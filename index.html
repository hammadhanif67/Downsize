Resize an image without uploading it

Downsize changes the dimensions of a JPG, PNG or WEBP image using your browser's own image tools. The file is read from your device and worked on there — it is never sent to a server, and no copy of it exists anywhere but your own machine. Pick a width, or choose one of the common sizes listed further down, and download the result.

How to resize an image

  1. Drop an image onto the page, or choose a file from your device.
  2. Enter the width you need. The height follows automatically unless you unlock the ratio.
  3. Check the before and after figures — dimensions and file size update as you type.
  4. Download the resized image.

Why resize in the browser

Most image tools work by uploading your file to a server, changing it there, and sending it back. That means a copy of your photo sits on hardware you do not control, for a length of time nobody tells you. Downsize does the work in the page itself, so there is no upload, no second copy, and nothing left behind to delete.

Skipping the upload also removes the waiting. There is no queue and no round trip, so a large photo is resized in well under a second and the preview keeps up while you are still adjusting the number. The only real limit is your own device.

There is also nothing to sign up for. No email, no free tier, no watermark on the way out, and no record that you were ever here. Open the page, do the one thing, close the tab.

Questions

Are my images uploaded to a server?

No. Downsize reads the image directly in your browser and does all the work there. The file never leaves your device, and there is no server involved at any point.

What file types can I resize?

JPG, PNG and WEBP. The image you download is always the same format as the one you opened, so a PNG stays a PNG.

Is there a file size limit?

Files up to 30 MB are accepted. The limit is checked before the image is opened, so a file that is too large is rejected straight away rather than slowing the page down.

Will resizing reduce the quality?

Making an image smaller keeps it sharp, because the detail is being condensed rather than invented. Enlarging past the original dimensions is allowed but will look soft, since there is no extra detail to draw on.

Does it cost anything?

No. Downsize is free, has no account, and adds no watermark. There is no paid tier to upgrade to.
